# KBM Contracts Repository (`kbm-platform-contracts`)

Contains OpenAPI v3.0 specifications and CloudEvents schema definitions for the KBM Platform:

- `procurement-api.yaml`: Tender intake, publication, and eligibility evaluation contracts.
- `workflow-api.yaml`: Workflow instance lifecycle and task transition schemas.
- `marketplace-api.yaml`: Microsoft Commercial Marketplace SaaS Fulfillment v2 API contracts.
