# KBM Platform UI (`kbm-platform-ui`)

Bilingual, accessible, responsive user interface supporting 4 persona portals and Microsoft Commercial Marketplace SaaS onboarding:

- **Internal Staff Portal**: Intake requests, GM letter scans, workflow approvals, evaluation checklists, tender publishing.
- **Vendor Portal**: Onboarding wizard, subscription management, eligible tender catalog, secure tender viewer with dynamic watermarking, KNET checkout, purchase receipts.
- **Tenant Administration Portal**: Workflow builder, SLA & role configuration, vendor grading/blocking/exemptions, branding settings, audit trail explorer.
- **Platform Operator Portal**: Cross-tenant management, marketplace subscriptions, feature flags, health diagnostics.
- **Marketplace Landing Experience**: SaaS customer onboarding, Entra ID SSO redirect simulation, plan activation.
